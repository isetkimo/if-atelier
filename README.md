# If Atelier 如果的室美學療癒所

## 上傳到 GitHub Pages

請把這個資料夾裡的內容全部上傳到你的 `if-atelier` repository：

- index.html
- style.css
- script.js
- images/hero.png
- images/room.jpg

記得：`images` 資料夾名稱要小寫，圖片檔名要一樣。

## 更換 LINE 連結

在 index.html 搜尋：

https://line.me/

全部換成你的 LINE 官方帳號連結。
