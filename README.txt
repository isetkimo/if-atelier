1. 把這個資料夾內所有檔案上傳到 GitHub repository 根目錄。
2. GitHub Pages 設定 Deploy from branch / main / root。
3. 以後要換照片，只要覆蓋 images 資料夾內同檔名圖片即可，不用改程式。
